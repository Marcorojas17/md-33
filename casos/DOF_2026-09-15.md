# 📄 Caso de Estudio Real · DOF 2026-09-15

**Aplicación del framework MD-33 a un documento público oficial**

---

## 🎯 Propósito

Este caso documenta la aplicación del **framework MD-33 v1.0** sobre un documento público real publicado en el **Diario Oficial de la Federación (DOF)** de México.

El objetivo es demostrar que el framework funciona sobre documentos reales, no solo sobre el caso demostrativo ficticio.

## 🔁 Paso 3 · Verificación cruzada con `sha256sum`

**Comando nativo (sin el script):**

```bash
sha256sum DOF_2026-09-15.pdf
```

**Resultado:**

```text

```

**Verificación en Windows (PowerShell):**

```powershell
Get-FileHash .\DOF_2026-09-15.pdf -Algorithm SHA256
```

## 🌐 Paso 4 · Anclaje del documento

Una vez calculado el hash, se procede a anclarlo para garantizar su existencia en una fecha determinada.

### 4.1 OpenTimestamps (Bitcoin)

```bash
ots stamp DOF_2026-09-15.pdf
# Genera: DOF_2026-09-15.pdf.ots

# Verificación inmediata (antes de confirmación en bloque):
ots verify DOF_2026-09-15.pdf.ots
```

**Resultado:**

```text
_____________________________________________________________
```

> ⏳ Nota: el anclaje en Bitcoin se confirma en ~1-2 horas. Para verificación inmediata, subir el `.ots` a https://opentimestamps.org/ al día siguiente.

## 🧠 Análisis del caso

### ¿Qué demostró este caso?

1. **El framework funciona sobre documentos reales.** No requiere el cristal MD-33 ni ningún elemento ficticio.
2. **El hash SHA-256 es universal.** Cualquier PDF, contrato, acta o evidencia digital puede ser verificada con las mismas herramientas.
3. **El anclaje blockchain es opcional pero potente.** Añade prueba temporal verificable globalmente.
4. **La plantilla de acta es directamente aplicable.** Solo hay que llenar los campos con los datos del caso real.

### ¿Qué NO demostró?

- La firma ECDSA no aplica a documentos del DOF (no están firmados digitalmente).
- La cadena de custodia física no aplica (el DOF no es evidencia física).
- El sello cabalístico es simbólico, no legal.
