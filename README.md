## 📖 ¿Qué es el Estándar MD-33?

El **Estándar MD-33 v1.0** es un protocolo internacional de verificación forense que combina:

- 🧬 **Narrativa ARG** — Un universo ficticio con lore verificable (Muelle 42, XT-77G, Fideicomiso Ciego 07)
- 🔐 **Criptografía aplicada** — SHA-256, ECDSA P-256, sellado de tiempo RFC 3161
- 🌐 **Anclaje blockchain** — Ethereum (EIP-191), OpenTimestamps (Bitcoin), IPFS
- ⚖️ **Cumplimiento legal** — ISO 27037, ISO 17025, LFDA, GDPR, Copyright Act 2007
- 🔯 **Capa cabalística** — Sello único con gematría hebrea y Atbash (Jesed · 1732)

Cualquier perito en México, USA, UE o Israel puede **clonar, verificar y aplicar** este estándar sin restricciones legales.

## 🚀 Inicio rápido

### 1. Clonar el repositorio

```bash
git clone https://github.com/Marcorojas17/md-33.git
cd md-33
```

### 2. Verificar un archivo

```bash
python src/verifica_estandar.py MANUAL_PERITO_INTERNACIONAL_MD33.md
```

### 3. Ver el checklist del perito

```bash
python src/verifica_estandar.py --checklist
```

### 4. Salida JSON (para integración)

```bash
python src/verifica_estandar.py --json MANUAL_PERITO_INTERNACIONAL_MD33.md
```

## 🧪 Verificación manual (sin software propietario)

### Hash SHA-256

```bash
sha256sum MANUAL_PERITO_INTERNACIONAL_MD33.md
# Esperado: a3f9c82e6b4d5f71b8e34d9c0f2a6e7d5b9c84e1f3d2b6a7c9e0d5f801
```

### Firma ECDSA

```bash
openssl dgst -sha256 -verify pubkey.pem \
  -signature firma_ecdsa.sig payload_XT-77G.bin
# Esperado: Verified OK
```

### Timestamp (OpenTimestamps)

```bash
ots verify payload_XT-77G.ots
```
